To ensure a validator operates effectively and efficiently, the minimum recommended hardware specifications are:
Component
Specification
CPU
32 cores, 2.8GHz or faster, AMD Milan EPYC or Intel Xeon Platinum
Memory
256 GB
Storage
5 TB SSD with at least 350MiB/s bandwidth and 30000 IOPS
Network Bandwidth
0.5 Gbps
Open Files Limit
ulimit -n ≥ 10000000
