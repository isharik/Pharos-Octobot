How the Skill Engine Works
What is a Pharos Skill?
A Pharos Skill is a folder of files that teaches an AI (Claude) how to interact with the Pharos blockchain. When you ask the AI something like
"Deploy a vault on Pharos"
, it reads your skill files to know exactly which commands to run.
The AI is smart but it does not automatically know your contract. You teach it by writing instruction files in plain Markdown. The AI reads those files and follows them precisely.
