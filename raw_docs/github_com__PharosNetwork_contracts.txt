System Contracts
Smart contract system for managing blockchain configuration, rules, access control, and staking functionality.
Overview
This repository contains core system contracts built with Solidity and Foundry, providing:
ChainConfig
- Blockchain configuration management
RuleManager
- Rule governance and enforcement
TransactionDeny
- Transaction blacklist control
Staking
- Proof-of-stake mechanism implementation
Requirements
Foundry
installed
Solidity 0.8.22
Installation
forge install
Usage
Build
Compile all contracts with IR-based optimization:
make build
#
or
forge build --via-ir --extra-output storageLayout
Test
Run the full test suite:

test
